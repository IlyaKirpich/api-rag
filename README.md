Задача:
Автоматизировать процесс принятия кредитных решений в банке с помощью LLM, способной анализировать характеристики заемщика, рассчитывать кредитный скор, оценивать риски и извлекать релевантные исторические кейсы для обоснования вердикта.

Решение:
Разработан proof-of-concept на базе Qwen2.5 (0.5B), развёрнутого в Docker-контейнере с FastAPI. Реализован MCP-сервис с инструментами расчёта кредитного скора и оценки рисков по метаданным (образование, брак и пр.), а также RAG-пайплайн с sentence-transformers и FAISS для поиска похожих кредитных историй. Настроен полный цикл инференса, включая промпт-инжиниринг (few-shot + CoT), и проведена оценка качества.

Итог:
Прототип обеспечивает сквозную обработку кредитной заявки с выдачей структурированного решения в формате JSON. На наборе данных Adult достигнуты метрики accuracy, precision, recall, f1, подтверждающие эффективность комбинации LLM, классических ML-тулов и RAG. Решение упаковано в Docker, готово к демонстрации и дальнейшему расширению.
