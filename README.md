# RAG-API — Retrieval-Augmented Generation Backend

API-сервис для семантического поиска и генерации ответов по пользовательским документам. Решает проблему "галлюцинаций" LLM, подгружая релевантный контекст перед формированием ответа.

## Возможности
- Загрузка документов
- Гибридный поиск
- Поддержка многопоточных диалогов
- Асинхронная индексация через Celery + Redis
- Кэширование эмбеддингов для повторяющихся вопросов
